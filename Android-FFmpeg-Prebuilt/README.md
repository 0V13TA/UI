# Bundled Android FFmpeg runtime

This library retains only the Android `arm64-v8a` FFmpeg 9.0 shared library
and headers used by the Odin video player. Unused command-line programs,
examples, and alternate prebuilt versions are intentionally not included.

The prebuilt was sourced from
[Android-FFmpeg-Prebuilt](https://github.com/hzw1199/Android-FFmpeg-Prebuilt).
See [LICENSE.md](LICENSE.md) for the applicable FFmpeg license information.
